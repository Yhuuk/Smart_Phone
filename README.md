# ***文档说明***
| 文件/目录            |     是否上传 | 原因                   |
| ---------------- | -------: | -------------------- |
| `src/`           |       上传 | 你的主程序代码              |
| `include/`       |       上传 | 你自己写的头文件             |
| `lib/`           |       上传 | 你自己写的本地库             |
| `test/`          |      可上传 | 测试代码，有就上传            |
| `platformio.ini` |     必须上传 | 项目配置、开发板型号、依赖库声明都在这里 |
| `.gitignore`     |     必须上传 | 告诉 Git 忽略哪些文件        |
| `.vscode/`       | 部分上传或不上传 | 看是否包含个人配置            |
| `.pio/`          |      不上传 | 编译缓存和依赖缓存            |
